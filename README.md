# 雪乡小仓买 · 冬夏村庄

一座被大山和森林环绕的东北小镇，以「雪乡小仓买」便利店为中心，在冬季雪夜和夏日晚霞之间切换。

## 村庄日常

便利店、炕房、熟食店、粮仓、修车棚和柴火棚各有用途，三座桥连起河岸。大爷坐班车去粮仓、回家，再乘车离开；大妈从家里出门购物，逛熟食店和小仓买后回家。

冬天有红灯笼、冰柱、炊烟、冰河和缓缓消退的雪地痕迹；夏天有西瓜、香瓜、纱门、风扇、窗下花圃和小葱地。点击燕子，可以看它绕一圈再落回；土狗会转头摇尾，冰柜里能取出小小的长方老冰棍。四种鱼沿河游动，偶尔浮到水面。

## 使用

拖动旋转、滚轮或双指缩放，双击聚焦；右上角切换冬夏，左下角重置，右下角预览并保存明信片。首次操作后启用声音，M 键静音。手机会显示横屏引导。

根目录 index.html 是可直接运行的自适应单文件网页；小工具目录为外置经典脚本横屏版。全部场景、纹理与环境声音均随项目提供或在本地生成，不依赖远程模型与音频。私人留言保存在访问者本地，不会提交到仓库。

## 版本

雪乡在建立本仓库前已完成多轮迭代，早期冬季版本曾随原多场景项目发布。v1.0.0 是独立仓库的首次打包发布，包含这些累积成果，并非场景初版。

- 冬季：山林与冰河、三座桥、各功能建筑、东北早餐和果蔬货架，逐轮完善村民购物与乘车路线、动物互动、门窗结构和碰撞避让。
- 雪夜氛围：补上逐渐被雪覆盖的脚印与车辙，以及灯笼和窗户投向雪地的柔和暖光。
- 夏季：在同一村庄加入晚霞、菜地花圃、纳凉摊位、流水鱼群和燕子，独立冬夏入口，并同步修正两季共用建筑与树木。
- 最近几轮：收拢小葱地避开道路；燕子可以起飞绕行后归巢；四种鱼补齐双侧眼睛，修正游姿与浮水动作。
